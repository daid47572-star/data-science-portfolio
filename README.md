## 📊 Featured Project

### Student Performance Analysis

**Status:** ✅ Completed

An end-to-end data science project analyzing the UCI Student Performance dataset to identify factors affecting student academic success.

**Key Findings:**
- Past failures are the strongest predictor of student success
- Study time positively correlates with final grades
- Absences negatively impact performance
- Parental education influences academic outcomes

**Tools:** Python, Scikit-learn, Pandas, Matplotlib, Seaborn
**Accuracy:** ~93% in pass/fail classification

[**View Project Repository →**](https://github.com/daid47572-star/data-science-project)

## 🚀 Deployment

This site is deployed using **GitHub Pages**:

1. Push all files to the `main` branch of the repository
2. Go to **Settings → Pages**
3. Select **Deploy from a branch**
4. Choose `main` branch and `/ (root)` folder
5. Click **Save**

The site will be available at: `https://[username].github.io/data-science-portfolio/`
